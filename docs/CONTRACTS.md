# 契約付款操作

新對局設定可勾選「啟用雙人契約付款」。設定在開局時保存，只套用新局。API、手動檔案與真人席位共用同一套契約流程。

## 固定條款

每份契約只有付款人與收款人。付款人選擇條件與付款分數，收款人接受後成立。

| 條件 | 觸發方式 |
|---|---|
| 收款人投紅／投藍 | 收款人本輪實際選擇指定顏色 |
| 雙方同色／異色 | 雙方本輪實際選色符合關係 |
| 付款人取得少數方獎金 | 付款人本輪實際獲得單人或雙人少數獎金 |

分數由提案者填入任意正整數，不限定兩分。數字需在系統可精確表示的整數範圍內（最多 9007199254740991）；簽約時不檢查餘額。條件按正式投票與原始少數獎金認定。

## 成立與解除

1. 付款人提出契約，系統向雙方提供完整條款與唯一契約編號。
2. 收款人對該編號確認接受。
3. 系統通知雙方「契約成立」後生效；聊天中答應、轉述或口頭承諾不算系統接受。
4. 已成立契約不能單方取消。投票前雙方各確認解除，收到系統解除通知後才失效；只有一方請求時原約仍有效。

契約僅限當輪，提出、接受與解除都只能在交涉期間進行；未接受提案在進入投票後不生效。每人可與多人簽約，也可和同一人簽多份。契約不強迫玩家選色。

系統只向雙方通知提案、成立、解除與個別結算，其他玩家與公開觀戰端不收到契約通知。玩家可自行轉述，但不代表官方驗證。總分仍公開，付款直接影響排名，不改變少數獲勝次數。終局上帝視角可重播完整契約紀錄。

## 操作入口

- 手動模式：每席 Markdown 已包含契約說明、行動格式、本人相關系統通知；照常整份貼給 AI，回覆貼回指定區並儲存。
- API 模式：AI 透過 propose_contract、accept_contract、cancel_contract 操作，正式通知保存在授權 history；通知會於下一邏輯窗口喚醒相關玩家，不需額外訂閱。
- 真人模式：「你的行動」內可選收款人、條件與分數並加入提案；收到提案後可加入接受，成立後可加入解除請求或同意解除。所有待送操作都需按「提交並推進」才送出。金額與條款在送出前會列在待送清單供核對。

同批行動不互相參照；只能接受前一批已收到的契約編號。請以系統正式通知確認結果。結算時雙方可查看本契約的實付金額與付款結果。
